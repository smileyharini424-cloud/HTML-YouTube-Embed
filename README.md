# HTML YouTube Embed

## Explanation

This program demonstrates how to embed a YouTube video inside an HTML webpage.

The iframe element is used to display the YouTube video directly on the webpage.

## Problem Statement

Create an HTML webpage that embeds a YouTube video using an iframe.

## Features

- Embeds a YouTube video
- Uses an iframe
- Sets video width and height
- Provides a video title
- Allows the video to be displayed inside the webpage

## How It Works

The <iframe> element creates an embedded frame.

The src attribute contains the YouTube embed URL.

The width and height attributes define the size of the embedded video.

The title attribute describes the embedded content.

The allowfullscreen attribute allows the video to be viewed in fullscreen mode.
